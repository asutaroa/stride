# STRIDE v2.1 — Interface Refinement

Changes in this version:
- Cleaner light mode styling with more complete theme overrides
- Bottom navigation reordered to Home · Live · Summary · Profile
- Profile icon moved to 4th tab with a person icon
- Summary moved to 3rd tab with a chart icon
- More profile customization options:
  - Display name
  - Short label
  - Daily step goal
  - Accent color
  - Coaching style
  - Appearance (dark, light, system)
- Profile settings still include coaching voice language, voice choice, and speech speed
- Live labels simplified for non-technical users
- Summary includes a simple goal-check metric

## Deployment
Replace the existing `index.html` in your GitHub Pages repository.
Keep your current `config.js` exactly as it is.
