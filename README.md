# STRIDE v2.6 — Simplified Bilingual Voice

- Removed the device voice selector from Profile settings.
- English and Korean voices are chosen automatically from available browser/device voices.
- Language selection and speaking-speed control remain.
- Other features from v2.5 remain.

Note: Browser Text-to-Speech uses voices available on the device. The app cannot guarantee an identical or studio-quality voice on every device.

## Deploy
Replace only `index.html` in the GitHub Pages repository. Keep the existing `config.js` and Supabase schema unchanged.
